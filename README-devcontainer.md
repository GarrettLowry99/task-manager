# Dev Container Setup Guide for Qt/C++ Projects

This guide explains how to set up a development environment using VS Code Dev Containers. This setup is designed for Qt/C++ projects, providing all necessary tools and configurations to build and test your activities and assignments.

---

## Prerequisites

- Install [Visual Studio Code](https://code.visualstudio.com/)
- Install [Docker Desktop](https://www.docker.com/products/docker-desktop)
- VS Code Extensions:
  - **Dev Containers** (by Microsoft): Essential for using dev containers.
  - **C/C++** (by Microsoft): Highly recommended for C++ development (often included in the dev container configuration via `devcontainer.json`).
  - **Qt Tools** (by Nasko): Helpful for Qt development, providing integration with Qt utilities (optional, may be included in `devcontainer.json`).

---

### Installing the Dev Containers Extension

1. **Open VS Code**.
2. **Access the Extensions View**:
   - Click on the **Extensions** icon in the Activity Bar on the side of the window.
   - Or press `Ctrl+Shift+X` (Windows/Linux) or `Cmd+Shift+X` (macOS).
3. **Search for the Extension**:
   - In the Extensions view search bar, type `Dev Containers`.
4. **Install the Extension**:
   - Locate **Dev Containers** by Microsoft in the search results.
   - Click the **Install** button.

---

### Installing Recommended C/C++ and Qt Extensions (Optional)

If the C/C++ and Qt extensions are not automatically installed by the dev container configuration:

1. **Open VS Code** (preferably after reopening in the container).
2. **Access the Extensions View** as described above.
3. **Search for the Extensions**:
   - In the Extensions view search bar, type `C/C++` and install the one by Microsoft.
   - Search for `Qt Tools` and install the one by Nasko (or another preferred Qt integration extension).
4. **Install the Extensions**:
   - Click the **Install** button for each.

---

### Installing Docker

Docker Desktop includes Docker for Windows and macOS. For Linux, you may need to install Docker Engine separately.

- **Windows and macOS**: Download and install [Docker Desktop](https://www.docker.com/products/docker-desktop).
- **Linux**: Follow the official installation guides for [Docker Engine](https://docs.docker.com/engine/install/).

Ensure Docker Desktop is running before proceeding.

## 📁 Folder Structure

This is an example structure for a typical Qt/C++ activity or assignment (e.g., after setting up a new project and then adding the `.devcontainer` folder):

```
 [activity_or_assignment_name]/  <-- This is the folder you open in VS Code

├── .devcontainer/                <-- Dev Container configuration
│   ├── devcontainer.json         <-- Main configuration file
│   └── Dockerfile                <-- Defines the Docker image for your dev environment
│
├── src/                          <-- Source code directory
│   ├── main.cpp                  <-- Main C++ source file
│   ├── myclass.h                 <-- Example header file
│   └── myclass.cpp               <-- Example source file
│
├── project_name.pro              <-- Qt project file (qmake) or CMakeLists.txt (CMake)
├── README.md                     <-- Activity/assignment instructions
└── build/                        <-- Build artifacts (generated by qmake/make or CMake)
```

### Steps to Set Up Your Development Environment with `.devcontainer`

1. **Ensure Docker Desktop is Running**

   - Open Docker Desktop on your machine.
   - Verify that the Docker engine is running. You should see the Docker icon in your system tray or menu bar indicating that it's active.

2. **Open Your Project (Activity/Assignment Folder) in VS Code**

   - Launch Visual Studio Code.
   - Use the **File > Open Folder...** option to open the root folder of your Qt/C++ project.

3. **Reopen in Dev Container**

   - VS Code should automatically detect the `.devcontainer` folder.
   - A notification will appear at the bottom-right corner:
     _"Folder contains a Dev Container configuration file. Reopen folder to develop in a container?"_
   - Click **"Reopen in Container"**.
   - If the notification doesn't appear, you can open the Command Palette (`Ctrl+Shift+P` or `Cmd+Shift+P`) and search for/run **"Dev Containers: Reopen in Container"**.
   - VS Code will now use the `devcontainer.json` and `Dockerfile` to build and start your development container.

4. **Wait for the Setup to Complete**

   - VS Code will show the progress of building the Docker image and starting the container in the terminal. This might take some time on the first run.
   - Once the container is ready, VS Code will connect to the dev container.
   - Any `postCreateCommand` or `postStartCommand` specified in `devcontainer.json` (e.g., installing additional C++ libraries, Qt components, or running initial build commands like `qmake && make` or `cmake . && make`) will run automatically.

5. **Start Working on Your Qt/C++ Project**

   - After the setup is complete, your development environment inside the Docker container is ready.
   - You can open a new terminal in VS Code (`Terminal > New Terminal`), which will now be a terminal _inside_ the dev container.
   - You can use build commands like `qmake`, `make`, `cmake`, etc., as usual, depending on your project setup.
   - All necessary C++ compilers, Qt libraries, and any extensions specified in `devcontainer.json` should be available.
